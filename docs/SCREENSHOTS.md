# Screenshot assets

`screenshots/upper-display.png` and `lower-display.png` are original RP Duo display captures, collected during a local Gemma 4 E2B demonstration. Values shown describe one short run, not a performance guarantee.

`screenshots/rp-duo-frame.png` is the user-provided device frame with its transparent outer edge cleaned. `screenshots/rp-duo-preview.png` contains the original display captures, scaled proportionally with Lanczos and pasted into the transparent screen windows. Neither screenshot is cropped, stretched or generatively redrawn.

Window coordinates are stored in `screenshots/rp-duo-frame.json`. Both windows are 720 px high: the upper is 1280×720 and the lower is 960×720. The composed window pixels were checked against independently resized source captures.
